Chapter 5 · YouTube

Data API & Researcher Program

A free API key in fifteen minutes, elevated quota through the Researcher Program, and the Google Researcher Program as the EU/DSA route.

What
YouTube Data API v3 (open to anyone, free) + YouTube Researcher Program (elevated quota for academics) + Google Researcher Program (EU DSA route, also covers Search, Maps, Play and Shopping).
Who
Data API: anyone with a Google account. Researcher Program: students, research staff or faculty at accredited not-for-profit degree-granting institutions (VUB qualifies).
Cost
Free.
Timeline
Data API key: ~15 minutes, self-service. Researcher Program: weeks to months (no published timeline).
Apply at
research.youtube.com / Google Researcher Program
Docs
developers.google.com/youtube/v3

Step one for everyone: a Data API key

  1. Sign in at console.cloud.google.com (institutional Google account recommended) and create a new Cloud project. No billing account is needed.
  2. In APIs & Services → Library, search “YouTube Data API v3” and click Enable.
  3. In APIs & Services → Credentials, create an API key. That key is all you need to read public data (OAuth is only required to access a user's private data, e.g., in data donation designs).
  4. Monitor your usage under IAM & Admin → Quotas.

Quota — note the 2026 restructuring

Since 1 June 2026, search.list and videos.insert each have their own separate bucket of 100 calls/day; the default 10,000 units/day covers all other endpoints. Most list reads (videos, channels, playlists, comments) cost 1 unit; every page of results costs again. Many older tutorials still describe search costing 100 units from the main pool — that is obsolete.

The YouTube Researcher Program (more quota)

  1. Check eligibility at research.youtube.com/how-it-works: affiliated with an accredited not-for-profit degree-granting institution; a clear research goal; findings published and publicly available; no Google/Alphabet affiliation. No topic restrictions.
  2. Create your Cloud project and enable the Data API first — the application asks for the project ID.
  3. Apply with your institutional email (@vub.be) at the researcher certification form, describing the project in as much detail as possible.
  4. Accept the program terms if approved. Note: YouTube obtains free access to research based on YouTube data after publication, and findings must be made publicly available. The granted quota is “as much as the research requires” (no published figure).

The EU/DSA route: Google Researcher Program

In effect, Google operationalises DSA Art. 40(12) through the Google Researcher Program: EU-affiliated, non-commercial researchers studying EU systemic risks can request access covering YouTube plus Google Search (including the Search Researcher Result API), Maps, Play and Shopping. A separate Google Trends API application is available from the same page. Apply at requestrecords.google.com/researcher — use a dedicated, non-personal Google account. For non-public data, the Art. 40(4) portal route applies; Google's contact is dsa-article-40-4@google.com.

What the APIs will not give you

No watch or search histories, no recommendation (“up next”) data, no impressions or user demographics (for channels you do not own), no dislike counts, no deleted videos. Recommender-system research still requires audit designs (sock puppets, crawls) or data donation — see the toolkit and ethics chapters before attempting either.
