Alt-tech & beyond

The platforms with no research doors at all — and the sources people look for that aren't platforms. What exists, what is tolerated, and what to use instead.

Alt-tech platforms: no research doors

None of these services is a designated VLOP, so no DSA route exists, and none runs a research programme. What follows is the tolerated-access map. See also the web-scraping paragraph and the ethics checklist — extremist-adjacent platforms raise researcher-safety and GDPR issues on top of the usual ones.

  • 4chan — the exception: an official, open, read-only JSON API (no key; max 1 request/second), and 4CAT collects 4chan natively.
  • Gab — a Mastodon fork whose API is effectively closed (public endpoints are largely Cloudflare-blocked; remnant endpoints answer inconsistently). Zeeschuimer captures Gab while you browse.
  • Truth Social — a Mastodon fork with no official API; researchers use account-based collection (Truthbrush) or Zeeschuimer, and a public dataset exists (Gerard et al., 2023).
  • Rumble — only a creator-facing Live Stream API for your own channel; no research access. Community scrapers and commercial vendors fill the gap.
  • BitChute — no official API; published studies run custom scrapers (e.g., the bitchute-scraper Python package).
  • Odysee — still operating after LBRY's 2023 shutdown (acquired by Forward Research in 2024); its backend JSON-RPC API answers without authentication but is undocumented and offers no stability guarantees.
  • Kick — launched its first official developer API in early 2025 (OAuth; channels, livestreams, chat events via webhooks). Early-phase, no research tier; the WebSocket chat feed most third-party tools read remains unofficial.

AI assistants (ChatGPT, Gemini, Claude, Copilot)

No API returns what users actually see in ChatGPT, Gemini, Claude or Copilot: the developer APIs serve the models, not the consumer apps. Questions about what assistants tell users are therefore squarely data-donation territory: recruit participants, have them export their chat history — a GDPR right, and ChatGPT and most rivals ship an export button — and donate a filtered subset.

Watch this space

ChatGPT was designated a VLOSE on 31 August 2026 — the first AI assistant under the DSA — so Art. 40 researcher-access obligations begin applying around the end of 2026. Watch the Commission's designated list and the Data Access Portal.

News and the open web

  • GDELT (blog.gdeltproject.org) — free global news monitoring: an events database back to 1979 updated every 15 minutes, the Global Knowledge Graph, a free DOC 2.0 API (about 1 request per 5 seconds) and full datasets on BigQuery. No registration.
  • Media Cloud (mediacloud.org) — open media-ecosystem research platform run by a UMass Amherst/Northeastern consortium: a 1-billion-story news archive, free account plus API key, and a maintained Python client.
  • Common Crawl (commoncrawl.org) — free web crawls released roughly monthly since 2007; anonymous HTTPS download plus a URL index.
  • Internet Archive / Wayback Machine (web.archive.org) — the CDX API lists captures per URL without a key; expect intermittent availability and build in retries.

Podcasts

The open door is Podcast Index — a free-key API over the open RSS podcast ecosystem whose core index “will always be available for free, for any use”. Spotify is the opposite story: in November 2024 it closed many Web API endpoints to new apps, and in February–March 2026 it restricted development mode much further (Premium account required, five authorised users per app, result limits and fields stripped). A minimal show/episode API technically remains, but Spotify is effectively unusable for research-scale podcast collection — build on Podcast Index and RSS instead.
