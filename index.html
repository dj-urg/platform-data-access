Read this first: time-sensitive changes

Reddit is closing its public Data API

New access requests are accepted only until 31 October 2026; the API closes entirely in March 2027. If anyone on your team may ever need Reddit data, file a request now.

X phased out API subscriptions in 2026

API access is now prepaid pay-per-use (about $0.005 per post read). The free academic track is long gone — but after a €120 million DSA fine in December 2025, X must give eligible EU researchers free access to public data.

Meta changed its application route in December 2025

Meta Content Library applications no longer go through ICPSR/SOMAR but through Meta's own Research Tools Manager, with independent review by France's CASD. Older guides describing the SOMAR route are obsolete.

The DSA ‘vetted researcher’ procedure is live

Since 29 October 2025, EU researchers can formally request non-public platform data through the European Commission's DSA Data Access Portal.

Why APIs matter for research

An API (Application Programming Interface) is “a set of features and rules that exist inside a software program (the application) enabling interaction with it through software — as opposed to a human user interface” (MDN Web Docs, n.d.). Where a platform's app or website is built for human eyes, its API is the doorway built for programs: you send a structured request (“give me all public TikTok videos with this hashtag posted in March”) and receive structured data back — typically JSON, ready for analysis.

  • Scale and precision. APIs return thousands of records in machine-readable form, with exact field definitions — no manual copying, no ambiguity about what a “view count” means.
  • Reproducibility and transparency. An API query can be documented, shared and re-run. Reviewers and collaborators can see exactly how a dataset was constructed (Peeters & Hagen, 2022).
  • A defined legal footing. Official research APIs come with terms of service that explicitly permit academic use — a far more solid position with ethics committees, data protection officers and journals than ad-hoc scraping (Ohme et al., 2024).
  • Access to data no browser shows. Many APIs expose metadata the interface hides: precise timestamps, forwarding chains, ad targeting parameters, aggregate engagement histories.

The post-API age — and the new EU era

Access has never been stable. After the Cambridge Analytica scandal (2018), platforms sharply restricted the open APIs that had fuelled a decade of social media research — what Freelon (2018) called the “post-API age” and Bruns (2019) the “APIcalypse.” Twitter's celebrated free Academic API was shut in 2023; CrowdTangle, the main window into Facebook and Instagram, was closed in August 2024; Reddit is closing its public API in 2027. Tromble (2021) describes the result: researchers dependent on platform goodwill, with unequal and unpredictable access.

Since 2024, however, the pendulum has swung back — in Europe. Article 40 of the EU Digital Services Act legally obliges the largest platforms to give researchers data access for studying systemic risks in the EU. Every major platform now runs a researcher access program because it must. This guide therefore treats the DSA as the backbone of platform data access, and each platform's own program as the practical doorway to it (Seiling et al., 2025).
