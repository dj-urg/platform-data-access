Chapter 3 · Meta

Facebook & Instagram

The Meta Content Library: public content across Facebook, Instagram, Threads and WhatsApp Channels — inside Meta's clean room, free of charge.

What
Meta Content Library (MCL): web interface + API over public Facebook, Instagram, Threads and WhatsApp Channels content. Successor to CrowdTangle (closed August 2024).
Who
Researchers at accredited, degree-granting, not-for-profit academic institutions, or qualified not-for-profit research institutions. Lead researcher cannot be an undergraduate (except for EU/DSA systemic-risk research).
Cost
Free, including Meta's Secure Research Environment compute.
Timeline
Roughly 4–6 weeks (CASD review 2–3 weeks + Meta processing 2–3 weeks).
Apply at
facebook.com/research-tools-manager (desktop only)
Docs
developers.facebook.com/docs/content-library-and-api

What data you get

  • Facebook: public posts from Pages, groups and events; posts from profiles with 100+ followers and verified profiles; Marketplace listings; comments.
  • Instagram: posts and accounts of business/creator accounts, personal accounts with 100+ followers, and verified accounts; comments.
  • Threads & WhatsApp Channels: public profiles with 100+ followers (Threads, not downloadable); verified or 100+ follower channels, last 30 days (WhatsApp).
  • Multimedia and engagement: photos, videos, reels; view counts above 100 views (Facebook from 2017, Instagram from October 2022).
  • API: 100+ fields across multiple endpoints; up to 100,000 results per asynchronous query (synchronous searches cap at 1,000 results).
  • Excluded: private content, ads (see Ad Library below), stories (mostly), and CrowdTangle-style live dashboards.

How to apply

  1. Read the application guide at developers.facebook.com → get-access.
  2. The lead researcher applies via the Research Tools Manager (link above), describing the research program, the institution and all collaborators, and chooses products: the MCL web UI and/or the API.
  3. For API work, choose a computing environment: Meta's Secure Research Environment (Jupyter-based, free) or ICPSR/SOMAR's Virtual Data Enclave (optional; USD 371/month plus a USD 1,000 setup fee, since January 2026).
  4. Your proposal is independently reviewed by CASD (France's Secure Data Access Center) — about 2–3 weeks; track status in the Research Tools Manager.
  5. Meta then verifies identity and has you accept the Research Tools Terms and an Information Sharing Agreement — another 2–3 weeks. On approval, invite collaborators from the dashboard (each is reviewed).
  6. Reapply via the Research Tools Manager if the research program changes substantially; notify institutional changes to metaresearchapplications@meta.com.

Limits and caveats

  • All API analysis happens inside the clean room: no raw-data download to your own machine; only vetted outputs (code, tables, figures, aggregates) can be exported. Installing extra packages/models in the environment is restricted.
  • Web UI quotas: 60 searches/minute; 500,000 results per rolling 7-day window; CSV downloads only for a narrower subset (large Pages and accounts), max 10 per day.
  • Coverage audits (e.g., Bekavac & Mayer, 2026) find MCL misses a substantial share of what users actually see in feeds, and removed content is least likely to be preserved — design and caveat accordingly.

Also useful: the Meta Ad Library

Separate and far more open: the Ad Library web UI is fully public (all active ads; EU ads retained at least a year with DSA targeting/reach data; political ads 7 years — frozen in the EU since 6 October 2025, when Meta stopped accepting new political ads there). The Ad Library API requires only identity verification (government ID via facebook.com/ID) plus a free developer app, and data can be downloaded locally. A practical starting point is The Markup's open-source script repository.
